# ReplyDesk

An interactive prototype of a WhatsApp lead agent that answers every inbound lead in seconds, with a live operations dashboard for the lead feed, pipeline, and response times.

**Case study:** [harshith-nayaka-l-portfolio.vercel.app/work/replydesk](https://harshith-nayaka-l-portfolio.vercel.app/work/replydesk): the problem, the architecture and the engineering decisions behind ReplyDesk.

## Try it

Open `index.html` in a browser, simulate an incoming lead, and watch it move through capture, reply and the pipeline in real time.

This is a self-contained front-end prototype with a simulate-lead demo, not a WhatsApp-connected production deployment. It proves the interaction and operations model, not a finished SaaS.
